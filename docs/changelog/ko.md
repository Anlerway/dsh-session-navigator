업데이트 안내: V1.2.0-Alpha-V1

주요 변경

미리보기 버전입니다. 설치해서 사용해 주시는 모든 분께 감사드립니다. 버그 제보와 제안도 언제든 환영합니다.

- 다국어 지원, 인터페이스 언어 여덟 개 추가
- 플러그인 코드를 재구성해 콜드 스타트 속도 개선
- 일부 상황에서 세션 삭제 후 목록이 갱신되지 않던 문제 수정
- 런타임이 없으면 바로 다운로드를 안내
- 데이터 디렉터리를 기본 위치로 되돌릴 수 있음
- 모든 대화 상자를 DSH 기본 대화 상자로 통일

자세한 변경

추가

- 언어 여덟 개 추가, 모두 열 개 (일본어, 한국어, 독일어, 프랑스어, 스페인어, 러시아어, 포르투갈어, 번체 중국어)
- AI 요약 진행률 표시줄
- Electron 구성 요소가 없으면 바로 다운로드 안내
- 설정 › 데이터 디렉터리: 위치 변경과 기본 위치로 복원
- 업데이트 안내도 다국어 지원

개선

- 콜드 스타트 3.1초 → 0.12초 (세션 2000개), 재시작은 세션 목록에서 읽음
- 새로 고침은 바뀐 파일만 읽음, 응답 한 줄로 전체 스캔이 돌지 않음
- 긴 목록은 보이는 줄만 생성, 첫 화면에서 요소 오만 개 이상 절약
- 세션 머리말과 통계를 파일 버전별로 캐시
- 검색 색인은 150밀리초마다 메인 스레드를 양보하고 세션당 본문에 상한을 둠
- 마우스를 올리면 강조가 즉시 반응
- 캐시 지우기에 두 항목 추가: 세션 목록과 내용 색인
- 대화 상자는 DSH 기본 대화 상자 사용
- 일부 문구를 다듬음

수정

- 세션 삭제: 열려 있는 세션도 휴지통으로, 「미분류」로 빠지지 않고 빈 폴더도 남기지 않음
- 패널이 가끔 비어 보임
- 삭제한 세션이 작업 공간에 남음
- 탐색기 창이 DSH 프로세스를 붙잡음
- 줄 메뉴 여백이 호스트 메뉴와 어긋남
- 런타임 이름이 Electron으로 표시됨
- 구성 요소 다운로드 진행률이 클릭에서 시작되지 않음

업데이트 안내: V1.2.0

주요 변경

이 버전은 1.2.0 정식 버전입니다. 설치해서 사용해 주시는 모든 분께 감사드립니다. 버그 제보와 제안도 언제든 환영합니다.

- 플로팅 볼 진입점: 끌어서 던질 수 있고, 떨어지면 튕깁니다. 다섯 가지 스타일을 고를 수 있으며 설정 › 진입 설정에서 선택합니다
- 다국어 지원, 인터페이스 언어 여덟 개 추가
- 플러그인 코드를 재구성해 콜드 스타트 속도 개선
- 독립 창 테마 적용과 dsh-plugin-wallpaper-engine 연동
- 독립 창이 GPU 가속 렌더링을 지원합니다. 기본으로 켜져 있으며 지원되지 않으면 자동으로 꺼집니다
- 일부 상황에서 세션 삭제 후 목록이 갱신되지 않던 문제 수정
- 런타임이 없으면 바로 다운로드를 안내
- 데이터 디렉터리를 기본 위치로 되돌릴 수 있음
- 모든 대화 상자를 DSH 기본 대화 상자로 통일

자세한 변경

추가

- 플로팅 볼 진입점: 사이드바 버튼과 별도로 끌어 옮길 수 있는 공이 생깁니다. 던지면 떨어져 튕기고 바닥에 멈춥니다. 다섯 가지 스타일(기본, DeepSeek, ChatGPT, Claude, Grok)을 바꿀 수 있으며 설정 › 진입 설정에서 선택합니다
- 언어 여덟 개 추가, 모두 열 개 (일본어, 한국어, 독일어, 프랑스어, 스페인어, 러시아어, 포르투갈어, 번체 중국어)
- AI 요약 진행률 표시줄
- Electron 구성 요소가 없으면 바로 다운로드 안내
- 설정 › 데이터 디렉터리: 위치 변경과 기본 위치로 복원
- 업데이트 안내도 다국어 지원
- 독립 창 꾸미기: dsh-plugin-wallpaper-engine 배경 화면을 따르거나 직접 올린 이미지를 사용, 흐림·유리·어둡기
- 독립 창에 GPU 가속 렌더링 모드 추가: 기본으로 켜져 있으며 설정 › 독립 창에서 끌 수 있습니다. 그래픽 카드나 드라이버가 지원하지 않으면 소프트웨어 렌더링으로 자동 전환됩니다

개선

- 콜드 스타트 3.1초 → 0.12초 (세션 2000개), 재시작은 세션 목록에서 읽음
- 새로 고침은 바뀐 파일만 읽음, 응답 한 줄로 전체 스캔이 돌지 않음
- 긴 목록은 보이는 줄만 생성, 첫 화면에서 요소 오만 개 이상 절약
- 세션 머리말과 통계를 파일 버전별로 캐시
- 검색 색인은 150밀리초마다 메인 스레드를 양보하고 세션당 본문에 상한을 둠
- 마우스를 올리면 강조가 즉시 반응
- 캐시 지우기에 세션 목록·세션 내용·Chromium 캐시·색인 추가
- 대화 상자는 DSH 기본 대화 상자 사용
- 일부 문구를 다듬음
- 설정 페이지의 열두 그룹을 용도 순으로 재배치

수정

- 세션 삭제: 열려 있는 세션도 휴지통으로, 「미분류」로 빠지지 않고 빈 폴더도 남기지 않음
- 패널이 가끔 비어 보임
- 삭제한 세션이 작업 공간에 남음
- 탐색기 창이 DSH 프로세스를 붙잡음
- 줄 메뉴 여백이 호스트 메뉴와 어긋남
- 런타임 이름이 Electron으로 표시됨
- 구성 요소 다운로드 진행률이 클릭에서 시작되지 않음
- 패널을 100%로 할 때 제목 표시줄이 가려지는 문제 수정
- 독립 창 오른쪽 위 세 버튼을 크게

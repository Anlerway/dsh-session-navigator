# 更新日志

十种语言各一份，文件名就是 `src/lang.js` 里的语言码。面板的「更新说明」按界面语言读这里（页面把语言码作为 `?lang=` 带上），那份不存在时退到 `en.md`，再退到 `zh.md`。

发布新版本时十个文件一起改：标题里的版本号、每节的条目数都保持一致，`test/notes.test.mjs` 会拿它们互相比对。

## 长什么样

每份都是同一副骨架，顺序不换：

```markdown
更新说明：V1.2.3        ← 标题，本地语言的「更新说明」+ 冒号 + 版本号

主要改动                ← 标题，本地语言

- 一条一句话，写这一版真正改了什么
- …
```

版本号可以比 `package.json` 提前一号（说明先写、版本号随发版改），但不能落后：`test/notes.test.mjs` 会拿十份的标题互相比对，并要求它不早于 `package.json`。

解析器不强制这个顺序（标题、列表、段落、粗体、行内代码就是全部语法），但十份都按它写：标题加一屏能读完的清单，不铺开详细改动，条数在十份之间对齐。

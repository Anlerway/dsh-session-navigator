# 更新日志

十种语言各一份，文件名就是 `src/lang.js` 里的语言码。面板的「更新说明」按界面语言读这里，那份不存在时退到 `en.md`，再退到 `zh.md`。

发布新版本时十个文件一起改：标题里的版本号、每节的条目数都保持一致，`test/notes.test.mjs` 会拿它们互相比对。

## 长什么样

每份都是同一副骨架，顺序不换：

```markdown
更新说明：V1.2.0-Alpha-V1        ← 标题，本地语言的「更新说明」+ 冒号 + 版本号

主要改动                                          ← 先给结论

这一版是什么性质，一句话。感谢的话放在这里。   ← 总述，一段

- 挑最大的几件事，六条上下，一条一句话

详细改动                                          ← 再给完整清单

新增

- …

改进

- …

修复

- …
```

解析器不强制这个顺序（标题、列表、段落、粗体、行内代码就是全部语法），但十份都按它写：先让人二十秒内知道这版值不值得看细节，再让人查到具体改了什么。
